วิธีติดตั้งเว็บบันทึกรอบบิลรายเดือน
====================================

ส่วนที่ 1: เปิดโปรเจกต์ใน VS Code
1. แตกไฟล์ ZIP นี้ลงในโฟลเดอร์ที่ต้องการ
2. เปิด Visual Studio Code
3. เลือก File > Open Folder... แล้วเลือกโฟลเดอร์ bill-tracker-google-sheets
4. ไฟล์เว็บคือ index.html, style.css, script.js
5. ทดลองเปิด index.html ในเบราว์เซอร์ได้ แต่แนะนำใช้ส่วนขยาย Live Server ใน VS Code
   - ไปที่ Extensions
   - ค้นหา "Live Server" และติดตั้ง
   - คลิกขวา index.html > Open with Live Server

ส่วนที่ 2: สร้าง Google Sheets
1. สร้างสเปรดชีตใหม่ที่ https://sheets.google.com
2. คัดลอก Spreadsheet ID จาก URL:
   https://docs.google.com/spreadsheets/d/นี่คือ_ID/edit
3. ใน Google Sheets เลือก Extensions > Apps Script
4. ลบโค้ดเดิมใน Code.gs แล้ววางโค้ดจากไฟล์ Code.gs ในโฟลเดอร์นี้
5. ในฟังก์ชัน setupSpreadsheet() แก้บรรทัด
   const id = "ใส่_SPREADSHEET_ID_ตรงนี้";
   ให้เป็น ID ที่คัดลอกมา เช่น const id = "1AbC...xyz";
6. กด Save
7. เลือกฟังก์ชัน setupSpreadsheet จากรายการด้านบน แล้วกด Run
8. อนุญาตสิทธิ์ให้สคริปต์เข้าถึง Google Sheets ของคุณ

ส่วนที่ 3: เผยแพร่ Apps Script เป็น Web App
1. กด Deploy > New deployment
2. กดไอคอนรูปเฟือง/Select type แล้วเลือก Web app
3. Execute as: Me
4. Who has access: Anyone (ถ้ามีตัวเลือกนี้และยอมรับว่าผู้ที่มี URL สามารถเรียก API ได้)
5. กด Deploy และอนุญาตสิทธิ์
6. คัดลอก Web app URL ที่ลงท้ายด้วย /exec

ข้อควรระวัง:
- URL นี้เป็น API ที่ไม่ได้มีระบบล็อกอินแยก ผู้ที่มี URL อาจอ่าน/เพิ่ม/แก้ไข/ลบข้อมูลได้
- อย่าใช้กับข้อมูลส่วนตัวหรือข้อมูลลับ หากต้องการใช้งานจริงแบบปลอดภัยควรเพิ่มระบบยืนยันตัวตน
- หากแก้ Code.gs ภายหลัง ให้ไป Deploy > Manage deployments > Edit > เลือก New version > Deploy

หมายเหตุ: เว็บเรียก Apps Script ด้วย JSONP เพื่อรองรับการเรียกข้ามโดเมนจากหน้าเว็บที่เปิดผ่าน Live Server\n\nส่วนที่ 4: เชื่อมเว็บกับ Google Sheets
1. เปิดหน้าเว็บ index.html ผ่าน Live Server หรือโฮสต์เว็บ
2. เลื่อนลงมาที่ "ตั้งค่าการเชื่อมต่อ Google Sheets"
3. วาง Web app URL ที่คัดลอกไว้
4. กด "บันทึก URL และเชื่อมต่อ"
5. ลองกรอกวันที่และจำนวนบิล แล้วกดบันทึก
6. ตรวจดูว่ามีแถวใหม่ใน Google Sheets

สูตรการคำนวณ
- บิลสุทธิ = max(0, บิลทั้งหมด - 25)
- ยอดเงินก่อนหัก = บิลทั้งหมด × 15 บาท
- ยอดเงินหลังหัก = บิลสุทธิ × 15 บาท
- หัก 25 บิลต่อวันที่มีการบันทึก ไม่ใช่หัก 25 บิลต่อเดือน
- ถ้าวันหนึ่งมี 20 บิล จะได้บิลสุทธิ 0 และยอดเงินหลังหัก 0 บาท
- บันทึกได้หนึ่งรายการต่อหนึ่งวัน การบันทึกวันเดิมจะเขียนทับข้อมูลเดิม

หมายเหตุ:
โหมด "ใช้โหมดทดลองในเครื่อง" เก็บข้อมูลใน Local Storage ของเบราว์เซอร์เท่านั้น
ข้อมูลโหมดทดลองไม่ได้ส่งไป Google Sheets และอาจไม่ปรากฏบนอุปกรณ์อื่น

แก้ไขประวัติรายวันและวันที่ใน Google Sheets:
- ใช้ Code.gs เวอร์ชันใหม่นี้แทนของเดิมใน Apps Script
- กด Save แล้ว Deploy > Manage deployments > Edit > New version > Deploy
- สคริปต์จะสร้าง/ปรับหัวตารางให้มีคอลัมน์ วันที่ และกำหนดรูปแบบ yyyy-mm-dd
- ข้อมูลเก่าที่ไม่มีวันที่จริงไม่สามารถเดาวันย้อนหลังได้ ต้องกรอกวันที่ให้รายการเก่าเอง
- ตรวจสอบว่าเลือกเดือนในหน้าเว็บตรงกับเดือนของรายการที่ต้องการดู
